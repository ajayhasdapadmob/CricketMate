Help / FAQs

Welcome to CrickMate Help
Find answers to common questions about matches, tournaments, live scores, profiles and CrickMate PRO.
What is CrickMate?
CrickMate is a cricket companion platform for managing matches, tournaments, teams, players, live scores and cricket activities.
How can I start a match?
Open the menu and select Start a Match. Enter the required match details and follow the scoring instructions.
How can I view live scores?
Open Live Scores from the home screen or menu. Available live matches will be displayed there.
How can I create a tournament?
Go to Tournaments / Series and use the available tournament creation option.
What is CrickMate PRO?
CrickMate PRO is a paid feature/service designed to provide additional CrickMate features.
Is PRO ₹199 an automatic subscription?
The CrickMate PRO option currently displayed as ₹199 is not presented as automatic autopay. Please check the PRO service terms before making a payment.
How can I contact CrickMate?
You can use the Contact page from the CrickMate menu.
